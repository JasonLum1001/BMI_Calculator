<h1>BMI Calculator</h1>

<p>A modern Android BMI (Body Mass Index) Calculator built with Jetpack Compose and Material 3. The application allows users to calculate their BMI using either the Metric or Imperial measurement system and instantly displays their BMI value along with its corresponding health category.</p>

<h2>Features</h2>
<ul>
  <li>Metric (Meter / Kilogram) support</li>
  <li>Imperial (Inch / Pound) support</li>
  <li>Input validation</li>
  <li>BMI calculation</li>
  <li>BMI category classification</li>
  <li>Modern Material 3 UI</li>
  <li>Responsive Jetpack Compose layout</li>
  <li>Clean MVVM architecture</li>
  <li>Custom BMI indicator (Gauge)</li>
</ul>
